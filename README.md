# Kimi Antonelli — GRIDO1 Racing Systems (demo)

Demo project — an unofficial fan concept of a driver site. Not affiliated with Kimi Antonelli, Mercedes-AMG F1 Team or Formula 1.

A single self-contained `index.html` (HTML/CSS/JS, three.js and Lenis from a CDN). Images and 3D assets are loaded from an external bucket.

Run locally: `python -m http.server 8765` and open http://localhost:8765.
